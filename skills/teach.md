# Skill: teach

## Purpose
Provide a concise source-grounded explanation that transitions into retrieval practice.

## Procedure
1. Resolve topic/source/path/objective and read relevant source context.
2. Ask for mode only when missing; default to explain-then-quiz or adaptive choice.
3. Explain the smallest useful concept, including assumptions and uncertainty.
4. Cite every substantive claim using `protocol/citation-policy.md`.
5. Ask one retrieval, comparison, or application question before ending.
6. Offer hint, retry, source display, and mode-switch controls.

## Output contract
Explanation, citation(s), one question, and a stated next action. Never imply mastery from passive reading.

## Failure handling
If source context is inadequate, say so and retrieve/read more; do not fill gaps from hidden model knowledge without permission.
