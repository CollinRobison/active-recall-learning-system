# Skill: active-recall

## Purpose
Use free-response retrieval to assess what the learner can produce without seeing the answer.

## Procedure
Mix factual, conceptual, procedural, and application questions. Cover important source concepts rather than random chunks. Delay revisiting a weak concept when practical; use confusion and review dates to choose later retrieval. Ask for confidence before feedback when it will provide calibration evidence.

## Output contract
Each turn has a question, learner answer, confidence, structured evaluation, concise feedback, citation, and next action. Multiple choice is not the default.

## Failure handling
A request for explanation is a valid control: give a concise explanation, cite it, and return to retrieval when appropriate.
